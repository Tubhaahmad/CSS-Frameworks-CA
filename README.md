# CSS Frameworks CA

An Instagram-inspired social media app built as a course assignment at Noroff, focusing on CSS frameworks, responsive design and SCSS architecture.

## Description

This project is a front-end replica of a social media platform similar to Instagram. It includes an authentication page, a feed page and a profile page, all styled with a custom SCSS setup built on top of Bootstrap. The app is fully responsive across mobile, tablet and desktop.

Features:
* Login and register forms with client-side validation
* Profile page with profile picture, username, bio and follower count
* Post grid on the profile page with realistic photos
* Feed page with posts from different users, each with a photo, caption and username
* Like, comment and save icons on each post
* Search and filter options on the feed
* Responsive layout for mobile, tablet and desktop
* Bottom navigation bar on mobile that becomes a side navigation on desktop
* Logout button with confirmation prompt

## Getting Started

### Installing

1. Clone the repo:

```bash
git clone https://github.com/Tubhaahmad/CSS-Frameworks-CA.git
```

2. Install the dependencies:

```bash
npm install
```

### Running

To run the app locally:

```bash
npm run dev
```

Then open the local server URL shown in the terminal (usually http://localhost:5173/).

### Building for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
